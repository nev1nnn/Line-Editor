# Line-Editor
Our Line Editor is created by Nevin Mathew(R25EF165), Pratham C(R25EF197), Nikhil B(R25EF168). Our Line Editor consists of features that are:
1. Insert a line
2. Delete a line
3. Display the document
4. Search
5. Find and Replace
6. Undo last action
7. Line count/Word count
How to Compile:
Make sure GCC is installed and added to the system PATH.
Open the terminal in the project folder and run:
gcc Line Editor.c -o Line Editor.exe
.\Line Editor.exe
